APUX is a web-based application framework that is designed to be compatible with modern web browsers. It is built using the latest web technologies and follows best practices for chromium based web browsers. APUX is designed to work seamlessly with the latest versions of popular web browsers, including:

- Google Chrome
- Microsoft Edge
- Brave
- Opera
- _and others_

The current version of Chrome is **138**.

**Notes:**

- Firefox is not supported.
- Many browsers, for example Edge, follow the version of Chrome.
